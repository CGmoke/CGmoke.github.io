## 三月的早晨

三月的阳光终于变得温柔起来，窗外的玉兰不知什么时候已经挂满了花骨朵，有几朵耐不住性子的，已经悄悄绽开了白色的花瓣。

坐在电脑前，手边是一杯还冒着热气的咖啡，屏幕上是昨天没调完的 ROS2 launch 文件。编译报错的红色提示依然在那，但好像也没那么令人烦躁了。

## 代码中的诗意

做开发久了，越来越觉得代码和诗歌有某种相似之处。

好的代码像一首好诗：
- 简洁，却意味深长
- 有节奏感，读起来朗朗上口
- 在最恰当的地方，给人惊喜

```cpp
// 这是一个简单的节点，但它承载着机器人的梦
int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    auto node = std::make_shared<RobotNode>();
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}
```

有时看着自己写的代码被编译通过、运行正常，那种满足感，大概和诗人写完一首满意的诗差不多吧。

## 技术之外

最近开始强迫自己每天离开键盘两个小时。

可能是去公园走一圈，看大爷大妈们晨练；
可能是去书店翻几页和技术完全无关的书；
可能就是在阳台发发呆，看看天空和云。

然后发现：
> 很多卡住的 Bug，离开屏幕后反而想通了。
> 很多纠结的技术选型，散完步就有答案了。

大概这就是「功夫在诗外」吧。

## 一些小目标

春天嘛，总是适合立 flag 的季节 🌱：

- [ ] 把 Nav2 的源码研究透，写一个系列笔记
- [ ] 学会用 Blender 做一些简单的机器人模型
- [ ] 周末至少有一天完全不碰代码
- [ ] 读完两本非技术类的书
- [ ] 学一首吉他指弹曲

## 写在最后

> 「代码改变世界，但别忘了看看这个被我们改变的世界。」

春日正好，愿你我既能在代码里乘风破浪，也能在阳光下笑得灿烂。🌸
